Introduction to the CSS cascade

The cascade is the algorithm that decides which declaration wins when more than one rule sets the same property on the same element. A reading mode must open on that title and keep the in-page table of contents that documentation layouts put beside the body.

Origin types

Declarations arrive from the user agent, the author, and the user. Each origin can also layer styles; the cascade walks origins and layers before it ever compares selector specificity.

A documentation page that marks this section with a fragment id is exactly what the in-page contents list points at. Those links must remain after furniture exclusion, unlike a site chrome control that only pretends to be a table of contents.
