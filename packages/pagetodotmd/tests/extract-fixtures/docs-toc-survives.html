Introduction

This manual describes the public surface of the library and how a caller is expected to wire the pieces together.

The table of contents is a nav of same-document fragment links and must survive extraction even though its link density looks like furniture.

Install

Install the package from the workspace and import the functions from the package root. No separate build step is required for consumers that read TypeScript from source.

API

The API is a small set of free functions. Nothing registers itself on import and nothing reads a global document at module scope.

Callers that already hold a live document pass it in; tests build a document under happy-dom and pass that instead.
